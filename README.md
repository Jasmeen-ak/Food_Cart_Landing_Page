# 🍕 Food Cart Website (HTML & CSS)

A clean and attractive **Food Cart / Restaurant Homepage** designed using **pure HTML and CSS**.  
This project showcases a modern food-themed layout with a hero section, menu items, gallery, and contact details.  
Perfect for beginners learning web design and layout structure.

---

## 🎨 Features
- Fully static website  
- Modern restaurant-style homepage  
- Clean top navigation bar  
- Hero banner with featured dishes  
- Menu / Popular Items section  
- Image gallery  
- About & Contact section  
- Pure HTML + CSS (no frameworks)
